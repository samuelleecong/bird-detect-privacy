BirdFrame sample files

This permanent test kit is provided for Apple App Review. It contains seven bird JPEGs that exercise the folder-import, on-device detection, crop review, and export workflow.

Download reviewer sample files

Quick test

  1. Download and expand the ZIP.
  2. Launch BirdFrame and complete onboarding.
  3. Choose Select Folder and select the expanded images folder.
  4. Choose Process All.
  5. Review the grouped detections, open a group, and save the resulting crops.

No account or internet connection is required. Detection runs locally with the Core ML model bundled in the app.
